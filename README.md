Hydrateless is a lightweight component library that delivers fast, accessible UI
primitives—like disclosure, tabs, table of contents, accordions, and
modals—using semantic HTML and modern CSS first, with no JavaScript by default.
It leans on native capabilities (e.g., `<details>` and the `:has()` selector) to
keep runtime cost near zero, then selectively auto-loads tiny JS enhancers only
when an interaction truly requires it. The timing is ideal as Core Web Vitals
budgets tighten and teams seek predictable performance across static sites and
JS-heavy frameworks alike. Version 1 would ship 8–10 fully a11y-complete,
themeable components (via CSS variables) plus optional, framework-agnostic JS
add-ons for advanced behaviors—delivering a pragmatic path to rich interfaces
without paying a constant JavaScript tax.
