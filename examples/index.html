What is Hydrateless?
A CSS-first component library that uses semantic HTML and modern CSS, with optional JS enhancers for interactivity.
Do I need JavaScript?
Most components work without JS. Enhancers add keyboard nav, focus traps, and ARIA wiring where native HTML falls short.
How do I theme it?
Override CSS variables like --hl-color-accent, --hl-radius-3, and --hl-spacing-4.
