# Hydrateless React example

A minimal Vite + React 18 app using `@hydrateless/react`. It showcases the
compound component API (`Tabs`, `Dropdown`, `Combobox`), a controlled `Modal`,
`Field` form controls, `Pagination`, and imperative toasts via `useToast`.

```bash
npm install
npm run dev
```

The app depends on the local packages via `file:` paths, so run
`npm run build` at the repository root first.
